# jsonrpc4cats

A library to write JSON-RPC protocols for the Scala programming language.
A port of jsonrpc4s using Cats-Effect 3 and FS2 libraries.

### Credits

Based on maintained [jsonrpc4s fork](https://github.com/alexarchambault/jsonrpc4s) by Alexandre Archambault.
Jsonrpc4s was an evolution of [lsp4s](https://github.com/scalameta/lsp4s).
